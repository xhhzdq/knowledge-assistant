## 剩余工作日 1：Compose 配置

预计 1.5～2 小时。

1. 固定 PostgreSQL、MinIO、Redis 镜像版本。
2. API 使用 `postgres:5432`、`minio:9000`、`redis:6379`。
3. 设置 `DOCUMENT_STORAGE_BACKEND=minio`。
4. 使用 MinIO 应用账号和 Redis 密码。
5. 完成四个健康检查。
6. 移除 `uploads_data` 过渡卷。
7. 运行 `docker compose config`。

产出：可解析、无明文默认密码的 `compose.yaml`。

## 剩余工作日 2：四服务启动

预计 2～3 小时。

```bash
docker compose build
docker compose up -d postgres minio redis
docker compose ps
docker compose run --rm api alembic upgrade head
docker compose up -d api
docker compose logs --tail=100 api postgres minio redis
```

验收 PostgreSQL、MinIO、Redis healthy，以及 API `/health` 返回 200。

## 剩余工作日 3：业务和持久化验收

预计 1.5～2 小时。

1. Swagger 上传文档。
2. MinIO Console 查看对象。
3. PostgreSQL 查询元数据和 Object Key。
4. 第一次 GET 产生 Redis Key，第二次 GET 命中。
5. PATCH 后缓存失效。
6. 停止 Redis，确认详情仍可回源 PostgreSQL。
7. `docker compose down` 后重新启动，确认数据仍存在。

产出：完整演示记录。
