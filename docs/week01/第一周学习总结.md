## 关键收获

- 模型、Repository、Service 和 CLI 的职责需要分开。
- dataclass 表示领域数据，TypedDict 描述持久化字典结构。
- Repository 管理元数据，Service 组织文件和元数据的一致业务操作。
- pytest、Ruff 和 mypy 分别检查行为、代码问题和静态类型。

## 遇到的问题及解决方式

- Ruff 建议使用 `datetime.UTC` 替代 `timezone.utc`，已修改并验证。
- JSON 直接覆盖存在中途损坏风险，改为先写临时文件再替换。
- 删除文件前检查目标路径必须位于 uploads 目录，避免错误元数据影响其他文件。
